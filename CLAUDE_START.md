# How to Start with Claude

## Step 1
Ensure `AGENT.md` exists in the root of the repository.

## Step 2
Open Claude Code or Cursor.

## Step 3
Send the first prompt:

```
Read AGENT.md in this repository and use it as the architectural contract.

Initialize the project following those rules.

Tasks:
1. Create NestJS base project
2. Create folder structure
3. Install dependencies
4. Create base modules

Do not implement business logic yet.

Summarize created files.
```
